# AutoConnectRush — планировщик Телемоста для Windows

**Бета 0.5.0.** Локальное приложение: расписание по Москве, ввод имени, подключение и выход. Не требует Codex, ChatGPT, Python или отдельной установки .NET. Доступ к камере, микрофону и захвату экрана запрещён; звук встроенного браузера выключен.

[Скачать сборки](https://github.com/entropyrpcommunicate-bit/autoconnectrush/releases) · [Исходники](https://github.com/entropyrpcommunicate-bit/autoconnectrush)

[Требования Edge](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-supported-operating-systems), [требования .NET](https://learn.microsoft.com/en-us/dotnet/core/install/windows).

## Установка — для друзей

1. Открой Releases и скачай нужный ZIP. В большинстве случаев это **win-x64**. Тип системы указан в Параметры → Система → О системе.
2. Полностью распакуй ZIP в отдельную папку. Не запускай EXE прямо из архива и не выноси его из папки: нужны DLL рядом.
3. Запусти `LessonPlanner.exe`. Права администратора приложению не нужны.
4. Если приложение сообщает, что WebView2 не найден, установи **Evergreen Standalone Installer** нужной архитектуры [с сайта Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/#download-section), затем перезапусти планировщик. На многих компьютерах Runtime уже есть.
5. Эта сборка не имеет коммерческой цифровой подписи издателя. Если Windows заблокировала её запуск, не отключай защиту системы: используй проверенную сборку или собери исходники самостоятельно.

Для передачи другу отправь **ZIP целиком**. Расписание и профиль браузера не хранятся рядом с EXE, поэтому в исходный архив сборки личные данные не включаются.

## Как пользоваться

1. Вставь полную ссылку комнаты (`https://telemost.360.yandex.ru/j/…`) и своё имя.
2. Нажми **«Автотест 90 с»** на тестовой встрече. Это реальное подключение с автоматическим выходом через 90 секунд. Во время первого теста наблюдай за окном. При возможности проверь с другого устройства, что участник появился и затем вышел.
3. Кнопка **«Ручная проверка»** только открывает страницу: автоматизация в этом режиме ничего не нажимает. Для тестирования сценария используй именно автотест.
4. Выбери дату, время входа и выхода **по Москве, UTC+3**. Скрытые секунды отбрасываются. Нажми «Добавить».
5. Можно добавить несколько непересекающихся заданий. Для двух пар в одной комнате можно задать общий интервал с перерывом.
6. Чтобы отменить одно задание, выбери строку и нажми «Отменить выбранное». Редактирование — через отмену и добавление нового.
7. Сворачивание убирает приложение в трей рядом с часами. Двойной щелчок по значку возвращает окно. Закрытие приложения прекращает выполнение расписания.

## Чтобы Windows не уснула

- Подключи питание, оставь ноутбук открытым и приложение запущенным.
- Пока есть ожидающие или выполняющиеся задания, планировщик вызывает штатную функцию Windows `SetThreadExecutionState`. Дисплей может погаснуть, автоматический сон от бездействия блокируется.
- Приложение не отменяет принудительный сон, закрытие крышки, выключение, обновление или перезапуск Windows. При выключенном компьютере работать не может.
- Дополнительно проверь Параметры → Система → Питание и батарея (или «Питание и спящий режим») → время перехода в сон при питании от сети. Для периода работы можно выбрать «Никогда», а после вернуть обычную настройку.
- Первый тест проведи в открытом пользовательском сеансе. Работа при блокировке, корпоративных политиках питания и после гибернации не проверена.

## Что автоматизируется

«Продолжить в браузере» → распознавание поля имени → заполнение и проверка → закрытие известного сообщения «Включить видео не удалось» → нажатие «Подключиться». Обрабатываются вложенные страницы Яндекса. При возврате на главную выполняется до трёх повторных переходов к комнате.

Кнопка входа имеет отдельную задержку повторного нажатия (12 секунд); сообщения продолжают обрабатываться каждые 0,75 секунды. Нажатие кнопки **не означает успешный вход**. Статус WebRTC показывает соединение транспорта, но не гарантирует допуск организатором или отметку посещения.

В конце интервала встроенный браузер уничтожается и соединения закрываются. Пропущенные более чем на две минуты задания не запускаются поздно; прерванная при закрытии пара не возобновляется автоматически. Авторизацию, CAPTCHA и незнакомые запросы нужно пройти вручную. Открытие новых окон авторизации автоматически не поддерживается.

## Ограничения и проверка

Исходники и сборка проверяются автоматически. Проверки расписания и сценария страницы не заменяют настоящую встречу. Windows-версия создана на Mac; успешный вход на Mac не доказывает работу Windows-версии. Смотри `VALIDATION.md` и статус Actions для актуальных результатов. До первого успешного автотеста не полагайся на приложение без наблюдения.

Время запуска планировщика не гарантирует момент подключения: есть загрузка браузера, сети и допуск. Непрерывное присутствие и восстановление соединения не гарантированы. Сайт может изменить форму.

Распознавания переклички, голосовых ответов и Telegram-уведомлений **нет**. Записи аудио/видео и отправки сообщений в чат тоже нет. VPN не нужен самому планировщику, но связь с Яндексом должна работать; приложение настройки VPN не меняет.

## Приватность

Данные сохраняются только в `%LOCALAPPDATA%\LessonPlanner\`: `jobs.json` и `BrowserProfile`. Имя и ссылка передаются Яндексу при подключении. Не публикуй и не отправляй эту папку друзьям. Приложение не собирает собственную телеметрию. Сетевые обращения WebView2 и Телемоста регулируются их поставщиками.

## Разработка и сборка

Нужен .NET SDK 10. Проект WinForms + WebView2; `Planner.Core` не зависит от Windows.

```powershell
dotnet run --project tests/Planner.Tests -c Release
node tests/automation.test.cjs
powershell -File scripts/publish.ps1 -Runtime win-x64
```

Другие архитектуры: `win-x86`, `win-arm64`. Runtime .NET включён в дистрибутив, WebView2 устанавливается отдельно. GitHub Actions проверяет код и создаёт ZIP для трёх архитектур; бета-релиз публикуется после успешных проверок основной ветки.
