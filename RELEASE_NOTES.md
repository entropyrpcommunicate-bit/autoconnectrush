Локальный планировщик Телемоста для Windows. Выберите архив своей архитектуры, полностью распакуйте и запустите LessonPlanner.exe. .NET включён; нужен установленный Microsoft Edge WebView2 Runtime.

- win-x64: большинство компьютеров Intel/AMD.
- win-x86: 32-битная Windows 10.
- win-arm64: Windows 11 ARM (Snapdragon).

Расписание по Москве, автотест 90 секунд, запрет камеры/микрофона/захвата экрана, отключённый звук, завершение по времени, удержание от автоматического сна.

Бета: сборка и автоматические проверки не подтверждают реальный вход в Телемост на каждом компьютере. Сначала проведите тестовую встречу. Подключение, допуск и непрерывное присутствие не гарантируются. Windows 7/8/8.1 не поддерживаются. Голосовых ответов и Telegram-уведомлений нет.

Сборки не подписаны сертификатом издателя. Не отключайте защиту Windows ради запуска. Инструкция и условия сторонних компонентов включены в архив.

## macOS

Добавлена версия Mac 0.4.1: **AutoConnectRush-macos-universal.zip** для macOS 13+ на Apple Silicon и Intel. Распакуйте архив и перенесите приложение в «Программы». Инструкция включена. Имя, комната и расписание в архиве отсутствуют. Подпись ad hoc, без нотариализации Apple. Самопроверка выполнена на Apple Silicon; запуск на Intel отдельно не проверен. Звук HTML-медиа приглушён; для полной тишины выключите системную громкость.

`AutoConnectRush-macos-source.zip` содержит соответствующие исходники Mac и скрипт сборки (они добавлены после исходного тега Windows v0.5.0). Контрольные суммы Mac — в `SHA256SUMS-macos.txt`.
